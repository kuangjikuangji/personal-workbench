# Task 8 自审报告

## 交付内容

- 个人科研页：文献完整 CRUD、阅读状态/年份/标签/全文筛选，以及独立学习方法 CRUD。
- 灵感页：快速记录、标签、置顶、归档、编辑，以及在仓储事务中复制转化为待办、科研记录或备课记录；新记录保留 `sourceType: 'idea'` 与 `sourceId`，原灵感不删除。
- 教学备课页：完整备课字段 CRUD、按课程分组和三种进度状态；关联课程删除时，记录正文保留并归组显示“原课程已删除”。
- 路由：`/research`、`/ideas`、`/lessons` 已从占位页接入真实页面。

## 自审清单

- 页面不直接访问 Dexie；所有读写通过 Repository，并由 TanStack Query 协调缓存刷新。
- 灵感转化的创建操作包裹在 `repositories.transaction()` 中，避免目标记录半写。
- 文献、学习方法、灵感、备课均有新增、查看、编辑和删除/归档路径。
- 新增测试覆盖文献四类筛选、学习方法独立 CRUD、灵感保留与转待办来源追踪、课程删除后备课保留、备课完整字段及分组显示。
