# 个人工作学习工作台

面向高校行政 + 教学科研双线场景的本地优先（local-first）工作台。电脑端浏览器即用，手机端可添加到主屏幕以接近 App 的体验。

## 模块一览
- **待办管理（工作模块）**：院长助理 / 系主任 / 个人待办 三类角色标识；添加 / 编辑 / 删除 / 提醒；录入时间冲突自动弹窗提醒；支持「微信对话智能导入」（粘贴对话自动解析日期、时间、角色为待办）。
- **日历**：月视图直接在格内显示待办内容与课表（按角色着色，非小点）；点击日期快速新建待办；冲突检测。
- **系室管理**：按年度记录教师主要工作 / 例会 / 教学材料 / 公共服务；批量操作（批量参会 / 缺席 / 请假 / 批量加材料 / 删除）；「一键补全未填报老师」；汇总导出 Excel / CSV。
- **个人科研（学习模块）**：文献阅读与方法笔记管理。
- **灵感记录**：随时添加留存想法。
- **教学备课**：备课内容整理与规划。
- **学生管理**：团队学生（研究生 / 学生助理）日常表现管理（分工 / 到岗组会出勤 / 任务推进 / 综合表现 / 备注），汇总导出 Excel / CSV。
- **课表**：录入每学期课程，自动出现在日历中。
- **设置 / 同步**：数据 JSON 备份与导入；清空；跨端 / 微信同步说明。

## 运行方式
方式一（推荐，避免浏览器本地文件限制）：
```bash
cd workbench
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
方式二：直接双击 `index.html` 用浏览器打开（部分浏览器在 file:// 下 localStorage 仍可用，但建议用方式一）。

## 桌面 / 手机使用
- 桌面：Chrome / Edge 地址栏右侧「安装」图标 → 作为独立应用固定到任务栏。
- 手机：浏览器打开同一地址 → 「添加到主屏幕」，即获得类 App 入口。

## 关于跨端与微信实时同步
- **本机版**数据存于浏览器 localStorage，适合单设备日常使用；「微信对话智能导入」作为微信同步的替代方案（粘贴对话即可解析为待办）。
- **真·多端实时同步 + 微信自动监听**：需将本应用部署到服务器（如 CloudStudio、自有主机）并接入账号体系与微信公众平台 / 企业微信 API，再扩展 WebSocket 实时同步与微信消息回调。本项目已采用清晰的单一数据层（`assets/data.js`），便于后续替换为远程后端。

## 数据说明
所有数据仅保存在你本机浏览器中，不上传任何服务器。请定期通过「设置 / 同步 → 导出备份」留存 JSON。
